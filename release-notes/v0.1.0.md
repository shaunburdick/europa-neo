## Europa Neo v0.1.0 — first tagged release

Europa Neo is an open-source TypeScript reimplementation of *Europa*, the 1990s Java-applet game of real-time nanobot warfare on Jupiter's icy moon. This is the first tagged release: the complete two-player MVP, self-hostable end to end on your own machine.

### Highlights

- **Deterministic game engine** — server-authoritative tick simulation; byte-identical state over 10,000-tick replay runs.
- **Procedural terrain** — deterministic, point-symmetric, balance-checked map generation for every seed.
- **Fog of war** — per-player visibility horizons with structural redaction; you only ever see what your nanobots sense.
- **Multiplayer networking** — authoritative WebSocket channel with heartbeats, idle sweeps, reconnection, and state resync.
- **Match lifecycle & matchmaking** — public and private (invite-link) matches with auto-start, rematch, and disconnect forfeit.
- **Browser console** — accessible satellite-view UI (keyboard-playable, screen-reader announced) under 150 KB gzipped.
- **Player manual** — thirteen pages covering every control and shipped number, published via GitHub Pages from `docs/manual/`.
- **Shared app versioning** — one `APP_VERSION` surfaced in the API handshake, `/version` endpoint, HUD footer, and docs, enforced by CI drift checks.
- **One-command local match** — `pnpm host` boots the matchmaker, match server, and console UI, then prints two join URLs.

### Getting started

See the [README quickstart](README.md): `pnpm install --frozen-lockfile && pnpm build && pnpm host`, then open the printed join URLs in two browser tabs.
