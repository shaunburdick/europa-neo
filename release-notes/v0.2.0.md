## Europa Neo v0.2.0 — multiplayer, Docker, and design system

This release expands Europa Neo from a two-player MVP to a fully scalable multiplayer experience with Docker deployment, a polished design system, and a much richer lobby and onboarding flow.

### Highlights

- **3–4 player support** — matches now scale to three or four players end-to-end, from terrain generation through networking to the browser console.
- **Docker one-command hosting** — `docker compose up` builds and runs the entire stack on a single port, ready for self-hosting.
- **Public lobby & match browser** — browse open matches, see live seat counts, and join or spectate from a shared lobby.
- **Elevation-based pipe flow** — pipe throughput now scales with terrain slope (downhill faster, uphill slower), with per-segment color-coding: green downhill, amber flat, red uphill, hollow stalled. Includes terrain smoothing for more natural maps.
- **Shareable design system** — `@europa/design` provides a single-source token table, deterministic CSS output, and a growing component catalog used by the console and player manual.
- **20 React UI components** — the full generic and game-specific component set, migrated from web components to React for tighter integration.
- **Semantic URL routing** — clean URLs like `/lobby`, `/match/<id>`, `/match/<id>/join`, and `/profile` replace query-string navigation.
- **Profile & identity onboarding** — a dedicated `/profile` route for setting and managing your player handle, with smooth onboarding for new visitors.
- **Welcome landing page** — a proper landing screen at `/` with logo, tagline, and quick links.
- **In-match help overlay** — press `?` during a match to see all controls and their current bindings.
- **Player manual on Astro** — the 13-page manual migrated from Jekyll to Astro with web component rendering and GitHub Pages deployment.

### Getting started

```bash
# Local development
pnpm install --frozen-lockfile && pnpm build && pnpm host

# Docker (single command)
docker compose up
```
