# Numbers

Every player-facing number in Europa Neo, exactly as shipped. When this table and the game disagree, the manual is wrong — report it as a bug. Each row names the constant it ships from.

## Simulation

| Value | Shipped value | Constant |
| --- | --- | --- |
| Tick cadence | 250 ms (4 ticks/second) | `DEFAULT_TICK_INTERVAL_MS` |
| City production | <europa-troop-chip count="1" owner="1"></europa-troop-chip> troop/tick until saturated | `ENGINE_CONSTANTS.productionRate` |
| City saturation cap | <europa-chip count="30"></europa-chip> troops | `ENGINE_CONSTANTS.cityCapacity` |
| Open-cell troop cap | 30 troops | `ENGINE_CONSTANTS.cellCapacity` |
| Unfed decay | −1 troop/tick | `ENGINE_CONSTANTS.decayPerTick` |
| Pipe flow, downhill | <europa-pipe-slope direction="downhill"></europa-pipe-slope> 8–12 troops/tick per pipe (Δ=1 → 8 … Δ≥5 → 12) | `ENGINE_CONSTANTS.flowBase + flowSlopeStep × min(│Δ│, flowSlopeDeltaCap)` |
| Pipe flow, flat | <europa-pipe-slope direction="flat"></europa-pipe-slope> 7 troops/tick per pipe | `ENGINE_CONSTANTS.flowBase` |
| Pipe flow, uphill | <europa-pipe-slope direction="uphill"></europa-pipe-slope> 6→1 troops/tick per pipe (Δ=1 → 6 … Δ=6 → 1) | `max(0, ENGINE_CONSTANTS.flowBase − flowSlopeStep × │Δ│)` |
| Pipe flow, stalled | <europa-pipe-slope direction="stalled"></europa-pipe-slope> 0 troops/tick (Δ≥7) | `ENGINE_CONSTANTS.flowBase / flowSlopeStep` (stall threshold) |

## Pipe slope intensity

These values control the visual triangle size on pipe slopes, not gameplay.

| Value | Shipped value | Constant |
| --- | --- | --- |
| Intensity formula (downhill) | `min(│Δ│, flowSlopeDeltaCap) / flowSlopeDeltaCap` → 0–1 | `PIPE_SLOPE_CONSTANTS.flowSlopeDeltaCap` (5) |
| Intensity formula (uphill) | `min(Δ, flowBase / flowSlopeStep) / (flowBase / flowSlopeStep)` → 0–1 | `PIPE_SLOPE_CONSTANTS.flowBase` (7) / `flowSlopeStep` (1) |
| Intensity (flat / stalled / fog) | 0 (no visual intensity) | — |
| Triangle min size | `max(2.4px, zoom × 0.06)` at intensity=0 (40% of base) | `cell-view.tsx` intensity scaling |
| Triangle max size | 6px at intensity=1 (100% of base) | `cell-view.tsx` intensity scaling |
| Canvas intensity scale | `(0.4 + intensity × 0.6)` × base size | `canvas.ts` `drawPipes` |
