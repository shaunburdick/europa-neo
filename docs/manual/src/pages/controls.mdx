# Controls

This page lists every pointer gesture and keyboard command available during a match. Open **Configure controls…** from the lobby before creating or joining, or from the existing pre-join screen before choosing **Play**. Configuration is optional and does not delay entry. Keep this page open during your first game. For what these commands do to the board, see [Pipes](./pipes), [Reserves](./reserves), and [Special weapons](./special-weapons).

Most commands act on your **selected cell** — the one highlighted by your last click or arrow-key move. The selected cell is also the launch point for paratroopers and guns.

## Pointer

| Gesture | Effect |
| --- | --- |
| Left-click near an edge of a cell | Toggle a pipe from that cell toward the clicked direction (north, east, south, or west). Click the same edge again to remove the pipe. |
| Right-click near an edge of a cell | Lay an **exclusive pipe** toward the clicked direction. This replaces all pipes in the cell instead of adding to them. |
| `Alt` + click near an edge of a cell | Same as right-click: an exclusive pipe toward the clicked direction. |
| Mouse wheel or middle-button drag | Camera control — see [Camera](#camera) below. |

> `Shift`+click currently behaves like a plain left-click. The modifier is reserved for a future multi-select feature.

| Key | Effect |
| --- | --- |
| <EuropaBadge>p</EuropaBadge> (or <EuropaBadge>h</EuropaBadge>) | Paratroop: launch from the selected cell to the target picked by your cursor's position (see [Aiming](#aiming-paratroopers-and-guns)) |

### Navigation

| Key | Effect |
| --- | --- |
| <EuropaBadge>Escape</EuropaBadge> | Cancel the current selection |
| <EuropaBadge>Arrow keys</EuropaBadge> | Move the selection one cell up, left, down, or right |
| <EuropaBadge>+</EuropaBadge> / <EuropaBadge>=</EuropaBadge> | Zoom in one step |
| <EuropaBadge>-</EuropaBadge> / <EuropaBadge>_</EuropaBadge> | Zoom out one step |

The Controls editor offers **Original**, **MMO / WASD selection**, and **Custom** keyboard profiles before match entry. Original is the default; MMO/WASD changes only selection movement to W/A/S/D and does not move troops, create pipes, or pan the camera. Custom edits and the selected profile remain in memory for the current runtime, including lobby-to-match navigation and rematches. Applying a keyboard profile keeps non-keyboard Gamepad bindings; reloading returns to Original.

## Gamepad

When the browser exposes the standard-mapped Gamepad API, the D-pad and left stick move the selected cell only. Holding a direction repeats selection movement at a bounded rate. Gamepad controls do not move troops, pan the camera, or create pipe orders by default. Open **Configure controls…** in the lobby or on the pre-join screen to inspect or change bindings before entering. Supported discrete buttons and signed-axis activations can be assigned to compatible existing actions; capture is local to the current runtime, is not saved, and resets when the page reloads. Without Gamepad API support, keyboard and pointer controls remain available. This behavior is not a guarantee for every controller or browser. **Physical controller smoke testing has not been performed; no hardware-validation claim is made.**

### Aiming paratroopers and guns

Pressing <EuropaBadge>p</EuropaBadge>/<EuropaBadge>h</EuropaBadge> or <EuropaBadge>g</EuropaBadge>/<EuropaBadge>o</EuropaBadge> fires from the **selected cell**. The target is picked by your cursor's position inside that cell — you never need to leave the cell to aim.

While a cell is selected, the cursor's position inside it acts as a miniature map of everything within 2 cells:

1. Click a cell you own to select it.
2. Keep the cursor inside the selected cell and slide it toward your target — up for north, lower-right for south-east, and so on. The farther from the center, the longer the throw: halfway to an edge aims about 1 cell out; the edge or a corner aims the full 2.
3. Press <EuropaBadge>p</EuropaBadge> (or <EuropaBadge>h</EuropaBadge>) for paratroop, <EuropaBadge>g</EuropaBadge> (or <EuropaBadge>o</EuropaBadge>) for gun.

A red aim dot on the selected cell shows exactly where you are pointing. Each new target cell is announced to screen readers as it changes. If the cursor is near the center of the cell, nothing launches — slide it off-center toward your target first.

Invalid targets are rejected with a short message above the order bar (see [Reading the screen](./reading-the-screen)):

- Water cells reject paratroops.
- Cells outside your vision are unreachable.
- Firing requires troops to pay the cost.

## Camera

| Gesture | Effect |
| --- | --- |
| Mouse wheel | Zoom in or out, keeping the point under the cursor pinned in place |
| Middle-button drag | Pan around the board |

A match starts at 100% of the measured board fit. The fit is measured once both the ready board view and viewport size are available, regardless of which arrives first; <EuropaBadge>Home</EuropaBadge> returns to it. The physical cell-size limits are 32–96 CSS px per cell. The effective maximum is `min(96px, fit size × 3)`, so the percentage ceiling can be below 300% when the fit size is larger than 32px. If the 32px minimum prevents the whole board from fitting, some of it may remain outside the viewport.

Panning works whether the board fits the viewport or overflows it. At 100% fit, you can move any corner cell's center to the center of the viewport; blank space outside a board edge is allowed. Blank margins are not board targets, so clicking there has no effect and issues no order. The minimap shows the part of the viewport that intersects the board, and clicking a minimap cell centers that cell in the main view. While the camera remains at its last auto-fit position, resizing recomputes the fit. Once you change the camera from that position, resizing preserves your camera.

## On-screen buttons

The console's clickable controls mirror the keyboard commands, so mouse-only play works end to end:

| Control | Where | Effect |
| --- | --- | --- |
| Mode badge ("Mode: Toggle pipes" / "Mode: Exclusive pipes") | Order bar, below the board | Shows whether your next pipe command adds or replaces. Announces changes to screen readers. |
| **Exclusive pipes** toggle | Order bar | Flip sticky exclusive mode: while engaged, every pipe command (pointer or <EuropaBadge>i</EuropaBadge>/<EuropaBadge>j</EuropaBadge>/<EuropaBadge>k</EuropaBadge>/<EuropaBadge>l</EuropaBadge>) replaces the cell's pipes instead of adding. |
| **Clear pipes** | Order bar | Clear all pipes in the selected cell (same as <EuropaBadge>Space</EuropaBadge>). |
| Reserves slider | Reserves panel | Drag or arrow-key a value from 0% to 90% in 10% steps for the selected cell. |
| Digit buttons 0–9 | Reserves panel | One-click presets matching the number keys ("Set reserves to 70%", and so on). |
| **Surrender…** | Below the order bar | Opens the confirmation dialog. Confirming eliminates you on the spot (see [Objective](./objective)); Cancel or <EuropaBadge>Escape</EuropaBadge> backs out. |
All order buttons disable themselves when orders cannot be sent — while connecting, reconnecting, spectating, or after the match ends.

The production active-match sidebar does not open the Controls editor. For embedded consoles, the host shell provides a separate launcher outside that sidebar.
